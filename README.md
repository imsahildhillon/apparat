# Apparat

Apparat is a Java-based web application for managing shared laboratory instruments in university environments.

It helps manage instrument availability, bookings, approvals, quotas, and utilization. Its central technical focus is concurrency: preventing multiple users from successfully reserving the same instrument for the same time slot.

## Technologies

- Java
- Servlet and JSP
- JDBC
- MySQL
- Multithreading
- Object-Oriented Programming
